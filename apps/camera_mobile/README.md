# EECC Caméra (Mobile Android & iOS)

Application mobile transformant un smartphone en caméra réseau sans fil pour EECC Studio.

## Fonctionnalités principales
- Appairage immédiat avec EECC Studio via scan de **QR Code** sur le réseau Wi-Fi local.
- Flux vidéo à faible latence (SRT / RTSP / WebRTC).
- Télémétrie en direct vers la régie : niveau de batterie, température, qualité réseau et niveau audio.
- Contrôles de prise de vue : bascule caméra avant/arrière, torche, verrouillage de mise au point et d'exposition.
