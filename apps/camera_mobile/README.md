# EECC Caméra (Mobile Android & iOS)

Application mobile transformant un smartphone en caméra réseau sans fil pour EECC Studio.

## Fonctionnalités de cette version
- Scan d'un QR produit par EECC Studio : adresse locale, port, jeton aléatoire à usage unique, expiration et empreinte du certificat.
- Envoi réel caméra + micro vers Studio sur le réseau local (WebRTC, vidéo VP8, audio PCMU). Aucun serveur externe.
- Tally aperçu / programme / attente uniquement lorsqu'un message est reçu. Batterie envoyée seulement si le téléphone la fournit.
- Contrôles : bascule caméra, torche si l'appareil la signale, zoom, micro réellement coupé, fermeture et relance.

Le mixage, l'enregistrement et la diffusion vers YouTube ou un autre service ne sont pas dans cette application.
